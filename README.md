# Praxiswebsite · Kai Läpple

Eine responsive, statische Website ohne Build-Schritt oder zusätzliche Pakete. Die Dateien können direkt bearbeitet und auf einem Webhosting veröffentlicht werden.

## Vorschau

`index.html` im Browser öffnen. Für eine lokale Servervorschau kann im Projektordner `python3 -m http.server 8000` gestartet und anschließend `http://localhost:8000` geöffnet werden.

## Öffentliche Vorschau

Die Website wird über GitHub Pages bereitgestellt: https://v8f8m8smjr-hub.github.io/praxis-laepple-website/ . Änderungen im Hauptzweig werden automatisch veröffentlicht.

## Vor einer Veröffentlichung ergänzen und prüfen

- Anfahrt einschließlich ÖPNV und Barrierefreiheit ergänzen. Die angegebene Anschrift und Telefonnummer vor Veröffentlichung bestätigen.
- Bestätigter Eröffnungstermin und Kontaktmöglichkeit für Anfragen.
- Vollständige Approbations- und Kammerangaben sowie zuständige Aufsichtsbehörden.
- Konkreten Altersbereich, angebotene Verfahren, freie Kapazitäten und Informationen zur Kostenübernahme ergänzen, sobald verbindlich geklärt.
- Impressum, Berufshaftpflichtangaben und Datenschutztext rechtlich prüfen lassen.
- Die Schriftarten werden aktuell von Google Fonts geladen. Für eine datensparsame Veröffentlichung die Schriftdateien lokal einbinden und die Datenschutzhinweise an den Webhost anpassen.
- Die Telefonnummer vor Veröffentlichung testen; das Postfach `praxis.laepple@gmail.com` regelmäßig betreuen.
- Der Anmeldebogen ist ein ausfüllbarer Vorabentwurf. Rückgabeweg und Datenschutzhinweise festlegen, bevor ausgefüllte Bögen angenommen werden.
- Die öffentliche Vorschau ist über GitHub Pages erreichbar. Die gewünschte eigene Domain ist noch nicht verbunden.
- Die Notfallhinweise und Rufnummern vor Veröffentlichung nochmals anhand der verlinkten offiziellen Stellen prüfen.
- Die Illustration im Abschnitt „Meine Person“ ist ein gestalteter Platzhalter, kein Porträt. Bei Bedarf durch ein eigenes Foto ersetzen.
- Geburtsdatum, Geburtsort, private Unterschrift und weitere persönliche Angaben aus dem Lebenslauf wurden nicht veröffentlicht. Anschrift und Telefonnummer stehen auf der Website, weil du sie ausdrücklich als Praxis-Kontakt angegeben hast.

## Domain

`praxis-laepple.de` und passende Varianten sind lediglich Domainideen. Verfügbarkeit, Registrierung und DNS-Einrichtung müssen separat bei einem Registrar geprüft und erledigt werden; diese Website behauptet keine Verfügbarkeit.
